Política de privacidad

Última actualización: 16 de noviembre de 2026

Uso de los Servicios de API de YouTube

Subidor Shorts utiliza los Servicios de API de YouTube para subir videos al canal de YouTube de su propietario. Al usar esta aplicación aceptas los Términos del Servicio de YouTube. El tratamiento de datos por parte de Google se rige por la Política de Privacidad de Google.

Qué datos se usan

  • La aplicación solo solicita el permiso youtube.upload, que permite subir videos a la cuenta autorizada.
  • Datos que se envían a YouTube: el archivo de video, el título, la descripción, las etiquetas y la configuración de privacidad y programación de cada video.
  • No se leen, recopilan ni almacenan datos de otros usuarios ni de otros canales, ni estadísticas, comentarios o información personal.

Almacenamiento y uso compartido

  • El token de acceso de OAuth se guarda únicamente en el ordenador del propietario y no se envía a ningún servidor ni a terceros.
  • No se comparte ni se vende ningún dato a terceros.
  • La aplicación no usa cookies, no tiene servidor propio y no incluye herramientas de seguimiento ni de publicidad.

Cómo revocar el acceso y eliminar datos

  • Puedes revocar el acceso de esta aplicación a tu cuenta en cualquier momento desde la página de permisos de seguridad de Google.
  • Al revocarlo, el token deja de funcionar. El propietario elimina además el archivo del token de su ordenador. Los videos subidos permanecen en YouTube y pueden borrarse desde YouTube Studio.
  • Para cualquier solicitud de eliminación de datos, escribe al contacto indicado abajo. Se atenderá en un plazo máximo de 7 días.

El uso de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.
