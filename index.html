Subidor Shorts

Herramienta personal que sube videos al canal de YouTube de su propio dueño mediante la API de YouTube.

Política de privacidad

Esta aplicación la usa únicamente su propietario para subir videos a su propio canal de YouTube.

  • No recopila, almacena ni comparte datos de ningún otro usuario.
  • El único permiso que solicita es el de subir videos (youtube.upload) a la cuenta de su propietario.
  • El token de acceso se guarda solo en el ordenador del propietario y no se envía a terceros.
  • No usa cookies ni herramientas de seguimiento.

El uso de datos de las API de Google cumple la Política de datos de usuario de los servicios de API de Google.
