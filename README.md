## Hi there 👋
Subidor Shorts
Herramienta personal que sube videos al canal de YouTube de su propio dueño.

Política de privacidad
Esta aplicación solo la usa su propietario para subir videos a su propio canal de YouTube mediante la API de YouTube. No recopila, almacena ni comparte datos de ningún otro usuario. El token de acceso se guarda únicamente en el ordenador del propietario. Contacto: nicolasfernandezp99@gmail.com
